# Fincard

一款经济题材的类肉鸽卡牌构筑游戏。你扮演一个国家的经济决策者，通过打出政策、改革与救济卡牌来影响国家经济，在期限内达成目标，并避免经济崩溃。

---

## 游戏目标

每个国家都会给出自己的**胜利条件**与**失败条件**：

- 满足全部胜利条件 → 获胜；
- 触发任意失败条件，或超出期限仍未达成目标 → 失败。

例如：把国内生产总值（GDP）提升到目标值以上，同时把通货膨胀控制在目标以下。

---

## 如何开始

1. 用 **Godot 4** 打开本目录并运行（F5）。
2. 在带有程序生成国旗的国家卡片中选择国家，查看国家背景、初始经济、目标与风险。
3. 在国家简介页点击「确认进入」开始；也可点击「返回主界面」或按 Esc 重新选择，不会提前开局。
4. 进入游戏后，先完成年度奖励与任命，自动领取国家年度收入，然后开始回合。首次推荐「新港共和国 · 入门」。

## 核心流程

一局游戏由若干**财年**组成，每个财年包含 8 个回合。

```
选择国家 → 国家简介 → 确认进入（或返回重选）
  → 首次年度筹备（领取奖励、任命内阁 → 自动发放收入）
  → 8 个回合（抽牌、出牌、结算）
   → 年度筹备（领取奖励 → 结转预算、发放年度收入）
  → 下一财年 …… 直到胜利或失败
```

**每个回合**的流程：

1. **回合开始**：政治行动点重置到本回合指定点数，不继承余额；可能触发一个随机事件（有时需要你做出抉择）。
2. **抽牌**：从牌库抽牌。
3. **出牌**：打出任意手牌，推进你的策略。
4. **回合结束**：结算经济、更新持续效果、检查胜负，然后进入下一回合。

**财年总结**（每年一次，第一年开局也会有）：

领取**财年奖励**：两组新卡、一个内阁、一项援助，**每组分别选一项**，也可以跳过。随后自动结算年度资源，不再选择预算案。长弹窗可向下滚动。

## 两种资源

打出卡牌需要同时支付两种资源：

| 资源 | 获取方式 |
| --- | --- |
| **财政预算** | 国家固定年收入，加上按系数保留的上年余额；修正可提高收入，救济可补充资金 |
| **政治行动点** | 每回合重置到指定点数（当前基础值3），不继承余额；修正可调整重置点数，事件、援助及内阁可当回合额外提供 |

两国年度奖励均可获得「政治协调」政策牌：普通「议会联络」消耗3预算和1政治点，获得3政治点；稀有「联合协商」消耗4预算和1政治点，获得5政治点；传奇「全国共识会议」消耗6预算和2政治点，获得8政治点。先支付费用，再获得点数，可立即用于其他卡牌，但不继承到下回合。

因此，能否出牌不仅取决于手牌，还取决于可用预算、财政制度与本回合可用的政治点。

## 卡牌、内阁与援助

- **卡牌**：分为「投资与援助」「政策」「改革」三类，每张都有预算成本与政治成本。卡面上的文字会直接列出它的具体作用。
- **稀有度**：另外分为普通、稀有、传奇、特殊四档。年度候选先按 **20:5:1** 权重抽前三档，再从该档可用卡牌中等概率抽取；特殊卡不会出现在年度奖励中，只能由事件、内阁或特定组合授予。没有可用卡牌的档位不参与抽取，初始牌组仍按国家固定配置。
- **提高奖励质量**：智囊团使稀有权重永久 +5；「政策研究网络」使稀有权重 +5、传奇权重 +1。加成可叠加，合并显示在统一修正栏；年度奖励显示当前权重，已生成的候选不会因任命内阁而重抽。
- **特殊卡**：任命智囊团获得「国家发展蓝图」，通过后永久提高潜在月增长0.2。特殊法案同样不可重复获得或重复通过。
- **效果上限**：每张卡最多两项效果，不重复发放经济联动的结果。投资通过限期增长带动产出、就业与物价；征税、节支等资金收入直接增加预算。
- **法案卡**：部分卡牌整局只能打出一次，打出后移除全部同名副本，也不会再次出现在奖励中。
- **特殊能力卡**：部分改革会永久改变出牌规则，而非直接加减经济指标。例如「行政授权法」让每回合第一张牌免政治成本，「专项发展基金」让首张投资预算 -2，「跨部门协调机制」让第三张牌后额外抽2张。
- **统一修正栏**：常驻参数只有潜在增长、通胀目标、自然失业率三个。改革、内阁等获得的额外数值修正和能力按需追加，同一属性合并为一个徽标；悬停查看基础值、净修正和到期后的变化。没有修正的财政参数、奖励权重不占徽标，仍可在预算栏、奖励窗和规则中查看。
- **内阁**：分普通、稀有、传奇、特殊四档，年度提供至多两个不重复候选，候选不足时按可用数量提供。先按与卡牌同步的有效权重（初始20:5:1）抽档，再抽该档内阁；权重修正同时作用于卡牌和内阁，特殊档不参与年度抽取。任命后显示头像与稀有度边框，悬停显示职务、档位与完整效果。
- **外部援助**：有限次数的消耗品，可在需要时主动使用。
- **财年奖励**：每年分别挑选两张新卡、一位内阁与一项援助，用于构筑你的阵容。

## 事件

- 普通回合有 **35%** 概率尝试触发随机事件，同一事件有冷却期，部分事件只在特定时期出现。事件效果需要确认或二选一。
- 某些国家拥有**定时事件**：在指定回合必定触发，通常用来表现历史剧情（例如大规模的经济危机）。

---

## 年度收入与财政制度

国家根据初始状态配置固定年收入：新港 **32**，阿卡迪亚 **40**。年度筹备任命的内阁会影响本次收入。

- 新预算 = `向下取整（上年余额 × 保留系数）+ 年度收入`。初始保留系数 **0.5**，改革可调整，范围为0～1；赤字余额使用同一公式。
- 「稳健扩张案」永久增加6年收入；「预算结转制度」永久增加0.25保留系数。财政部长与发展顾问也能永久提高收入。
- 救济既有即时资金，也有「过渡财政救济」：接下来两次年度发放各增加6收入，不按月递减。
- 「赤字财政改革」解锁永久特殊修正：允许卡牌和付费事件透支预算，但政治成本仍须支付。解锁前余额不足时不可支出。
- 政治点每回合重置为 `max(0, 每回合基础值 + 重置加成)`，开局与跨年同样执行，不额外提供开局6点。一次性加减只影响当前回合；年度内阁奖励在重置后发放。

预算是唯一的资金账户：卡牌按标示成本扣预算，加税、援助和变卖储备直接加预算，不另记借款或税收指标。旧预算案已取消，部分内容迁移为单独卡牌。

## 经济指标

游戏界面会显示以下经济指标，它们相互影响：

| 指标 | 含义 |
| --- | --- |
| 国内生产总值（GDP） | 国家经济总量，通常是要提升的核心目标 |
| 通货膨胀 | 物价上涨速度，过高会打击信心 |
| 失业率 | 失业人口占比，过高会影响支持与稳定 |
| 市场信心 | 市场对经济的信心，越高越有利于增长 |
| 利率 | 借贷成本，可用来抑制通胀或刺激经济 |

经济只保留 GDP、通胀、失业、市场信心和利率五项指标，另显示派生的月增长率。信心推动增长，增长降低失业并推高通胀，物价偏离目标会打击信心；利率影响增长和物价。预算余额本身不自动刺激经济。

基础经济模型仅有三个参数：潜在月增长 **0.18**、通胀目标 **2**、自然失业率 **6**。增长由潜在增长、信心与利率共同决定；通胀、失业与信心使用简短的固定联动规则，不再分别配置中性值和十余个敏感度系数。额外通胀回归、就业回归等由实际获得的内阁或改革解锁，默认没有效果，也不显示空徽标。

## 游戏界面

- **顶栏**：当前财年、回合数、财政预算、政治行动点与游戏状态。
- **顶部效果栏**：内阁头像、统一修正徽标，以及右上角可直接使用的援助；悬停显示详情。
- **左栏**：最终目标与经济指标，不再逐条列出修正。
- **牌桌**：本回合成功打出的牌按顺序重叠摆放，编号对应出牌顺序。悬停抬起旧牌，新回合清空；长序列可横向滚动。
- **底部手牌**：手牌横向排列，可出的牌以绿色边框标记，资源不足的牌置灰。手牌过多时横向滚动，底部保留牌库/弃牌数量及「结束回合」按钮。
- **右侧栏**：默认收起，点击「显示日志」展开，再次点击收起。上半部显示实时下回合预测与代入当前参数的经济公式，下半部保留事件日志；「规则与边界」可展开查看抽牌、回合、资源、事件概率和数值限制。
- **弹窗**：随机事件抉择、财年奖励、胜负结算。

把鼠标移到卡牌、内阁、援助上会显示完整效果；预算栏显示年收入，悬停可查看结转系数和赤字权限。

预测按立即结束当前回合计算，包含现有内阁、临时修正到期和跨年资源结算，不包含未来事件效果或新奖励。存在未完成的事件或年度选择时暂停预测，完成选择后刷新。预测使用独立状态与随机数副本，不改变真实局面。

## 玩法提示

- **资源要精打细算**：预算和行动点每回合都有限，优先打出最有价值的牌。
- **关注通胀与失业的平衡**：压制通胀往往会让增长放缓、失业上升；刺激增长又可能推高通胀。
- **保留应急预算**：未解锁赤字财政时，救助与补贴事件余额不足只能选择不花钱的方案。
- **永久性法案要慎重**：改动经济规则或长期加成很强，但一次性卡牌整局只有一张。
- **危机前提前布局**：在定时事件到来之前准备好应对手段，例如维持较高的信心与可用的援助。
- **按需出牌**：低通胀时不要反复稳价，就业良好时可以把预算留给投资；未使用手牌会在月末进入弃牌，随后还能洗回。

数值公式、全部卡牌与预算表见 [`economy.md`](economy.md)。

### 内阁头像资源

头像保存在 `assets/portraits/`，游戏运行不需要联网或 API 密钥。使用 GLM-Image 生成，随机人物外貌与生成提示词保存在同名 JSON 文件中。

重新生成资源需安装 Python 与 Pillow，并在环境变量中设置 `ZHIPU_API_KEY`：

```sh
python tools/generate_cabinet_portraits.py
```

默认仅补齐缺失头像；`--overwrite` 会重新生成全部头像。生成会调用智谱付费图像接口，密钥不写入资源文件。
