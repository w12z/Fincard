# Fincard

一款经济题材的类肉鸽卡牌构筑游戏。你扮演一个国家的经济决策者，通过打出政策、改革与救济卡牌来影响国家经济，在期限内达成目标，并避免经济崩溃。

---

## 游戏目标

每个国家都会给出自己的**胜利条件**与**失败条件**：

- 满足全部胜利条件 → 获胜；
- 触发任意失败条件，或超出期限仍未达成目标 → 失败。

例如：把国内生产总值（GDP）提升到目标值以上，同时把通货膨胀控制在目标以下。

---

## 如何开始

1. 用 **Godot 4** 打开本目录并运行（F5）。
2. 在带有程序生成国旗的国家卡片中选择国家，查看国家背景、初始经济、目标与风险。
3. 在国家简介页点击「确认进入」开始；也可点击「返回主界面」或按 Esc 重新选择，不会提前开局。
4. 进入游戏后，先完成年度筹备（选择预算案与奖励），然后开始回合。首次推荐「新港共和国 · 入门」。

---

## 核心流程

一局游戏由若干**财年**组成，每个财年包含 12 个回合。

```
选择国家 → 国家简介 → 确认进入（或返回重选）
  → 第一财年总结（选择预算案 + 领取奖励）
  → 12 个回合（抽牌、出牌、结算）
  → 财年总结（选择下一年预算案 + 领取奖励）
  → 下一财年 …… 直到胜利或失败
```

**每个回合**的流程：

1. **回合开始**：补充少量政治行动点，并可能触发一个随机事件（有时需要你做出抉择）。
2. **抽牌**：从牌库抽牌。
3. **出牌**：打出任意手牌，推进你的策略。
4. **回合结束**：结算经济、更新持续效果、检查胜负，然后进入下一回合。

**财年总结**（每年一次，第一年开局也会有）：

1. 确定下一年度的**预算案**（必须选择）；
2. 领取**财年奖励**：两组新卡、一个内阁、一项援助，**每组分别选一项**，也可以跳过。长弹窗可向下滚动。

---

## 两种资源

打出卡牌需要同时支付两种资源：

| 资源 | 获取方式 |
| --- | --- |
| **财政预算** | 每财年按所选预算案重新给满，用于支付卡牌的预算成本 |
| **政治行动点** | 每财年获得一大笔，此外每回合获得一小笔，用于支付卡牌的政治成本 |

因此，能否出牌不仅取决于手牌，还取决于你每年选定的预算规模与行动点积累。

---

## 卡牌、内阁与援助

- **卡牌**：分为「投资与援助」「政策」「改革」三类，每张都有预算成本与政治成本。卡面上的文字会直接列出它的具体作用。
- **法案卡**：部分卡牌整局只能打出一次，打出后移除全部同名副本，也不会再次出现在奖励中。
- **特殊能力卡**：部分改革会永久改变出牌规则，而非直接加减经济指标。例如「行政授权法」让每回合第一张牌免政治成本，「专项发展基金」让首张投资预算 -2，「跨部门协调机制」让第三张牌后额外抽2张。
- **能力徽标**：生效后的能力显示在左侧「特殊能力」栏；图标下显示可用次数或联动进度，悬停可查看完整说明。手牌显示实际费用及原价，自动按折后成本判断能否出牌。
- **内阁**：相当于遗物，任命后永久生效，可提供持续加成或每回合自动触发效果。
- **外部援助**：有限次数的消耗品，可在需要时主动使用。
- **财年奖励**：每年分别挑选两张新卡、一位内阁与一项援助，用于构筑你的阵容。

---

## 事件

- 普通回合有 **35%** 概率尝试触发随机事件，同一事件有冷却期，部分事件只在特定时期出现。事件效果需要确认或二选一。
- 某些国家拥有**定时事件**：在指定回合必定触发，通常用来表现历史剧情（例如大规模的经济危机）。

---

## 预算案

每年你必须从若干**预算案**中选择一个。预算案决定：

- 下一年度的财政预算总量；
- 下一年度政治行动点的补充量；
- 选定瞬间产生的一次性影响（例如影响市场信心、政府债务或通胀预期）。

预算案提供全年资源，并立即承担相应融资成本；经济也会根据利率、税率、就业与信心自然演变。

---

## 经济指标

游戏界面会显示以下经济指标，它们相互影响：

| 指标 | 含义 |
| --- | --- |
| 国内生产总值（GDP） | 国家经济总量，通常是要提升的核心目标 |
| 通货膨胀 | 物价上涨速度，过高会打击信心 |
| 失业率 | 失业人口占比，过高会影响支持与稳定 |
| 政府债务 | 政府欠债总额，过高会增加利息负担 |
| 市场信心 | 市场对经济的信心，越高越有利于增长 |
| 利率 | 借贷成本，可用来抑制通胀或刺激经济 |
| 税率 | 税收比例，提高税率可增加收入但会拖累增长 |

各指标之间存在联动，例如：信心上升会推动增长，增长会降低失业并推高通胀，通胀又会反过来压制信心；债务过高会不断增加利息负担。这些关系在游戏中是缓慢演变的，需要你通过出牌主动干预。

---

## 游戏界面

- **顶栏**：当前财年、回合数、财政预算、政治行动点与游戏状态。
- **左栏**：最终目标、经济指标、生效中的效果、已任命内阁、持有的外部援助。
- **中栏**：手牌、牌库/弃牌数量，以及「结束回合」按钮。
- **右栏**：事件日志，记录每回合发生的事。
- **弹窗**：随机事件抉择、预算案选择、财年奖励、胜负结算。

把鼠标移到卡牌、内阁、援助或预算案上，会显示它的完整说明与效果。

## 玩法提示

- **资源要精打细算**：预算和行动点每回合都有限，优先打出最有价值的牌。
- **关注通胀与失业的平衡**：压制通胀往往会让增长放缓、失业上升；刺激增长又可能推高通胀。
- **控制债务**：债务过重会持续加重利息负担，形成恶性循环。
- **永久性法案要慎重**：改动经济规则或长期加成很强，但一次性卡牌整局只有一张。
- **危机前提前布局**：在定时事件到来之前准备好应对手段，例如维持较高的信心与可用的援助。
- **按需出牌**：低通胀时不要反复稳价，就业良好时可以把预算留给投资；未使用手牌会在月末进入弃牌，随后还能洗回。
